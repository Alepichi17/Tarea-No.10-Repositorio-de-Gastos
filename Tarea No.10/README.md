# Tarea No.10 Repositorio de Gastos

## Descripción

Programa desarrollado en C# que utiliza:

- Cadena de conexion a Base de datos
- INSERT INTO VALUES
- DELETE FROM
- Creacion de GastosDB en (localdb)\MSSQLLocalDB
- using
- SqlConnection
- SqlCommand
- SqlDataReader
- .ExecuteReader()
- .Read
- .Parameters.AddWithValue
- @Valor
- .GetInt32()
- .GetString()
- .GetDecimal()
- Interpolacion
- Ternario
- if
